# Module 14 Glossary

| Term | Meaning in this module |
|---|---|
| Authority | The component permitted to decide and durably record a fact. |
| Backfill | Bounded migration of existing state into a new representation or projection. |
| Boundary ledger | Evidence table comparing the independence a boundary buys with its interface cost. |
| Branch by abstraction | Introduce a stable seam, place old and new implementations behind it, then switch incrementally. |
| Compatibility window | Period and population during which specified old and new versions must interoperate. |
| Contract | Fields, meanings, behavior, errors, timing, security, and lifecycle promised at an interface. |
| Contraction | Removal of old schema or behavior after migration and rollback obligations end. |
| Cutover | Controlled transfer of traffic or authority to a candidate path. |
| Decommission | Evidence-based removal of old code, data, infrastructure, access, operations, and cost. |
| Dual write | One logical change sent independently to two destinations, creating partial-failure risk. |
| Expand and contract | Add compatible capability, migrate and observe, then remove old behavior. |
| Fully loaded cost | Direct, shared, labor, transition, and expected-risk costs included in a decision. |
| Good outcome | A delivered unit that satisfies the declared correctness and service guardrails. |
| Interaction mode | Collaboration, service consumption, or facilitation between teams. |
| Paved road | Supported optional implementation path intended to reduce repeated cognitive and operational work. |
| Projection | Derived state rebuilt from an authoritative fact stream. |
| Reconciliation | Comparison that identifies missing, extra, stale, or different state and records repair. |
| Shadow traffic | Candidate execution whose results are compared but do not control authoritative effects. |
| Strangler migration | Incremental displacement of behavior behind seams rather than one replacement cutover. |
| Transitional architecture | Temporary components that reduce migration risk and have explicit removal conditions. |
| Unit cost | Fully loaded comparison cost divided by good useful outcomes. |
