# Module 00 Glossary

- **Amortized cost**: Average cost over a sequence where rare expensive steps are charged across many cheap steps.
- **Asymptotic complexity**: Growth behavior as input size increases, independent of a specific machine.
- **Big-O**: An upper-bound growth class.
- **Hash table**: A structure that maps keys to buckets using a hash function and collision policy.
- **Locality**: Reuse of nearby memory that makes hardware caches effective.
- **Priority queue**: A structure that returns the highest-priority item before lower-priority items.
- **Tractability**: Whether exact solution cost stays usable as problem size grows.
