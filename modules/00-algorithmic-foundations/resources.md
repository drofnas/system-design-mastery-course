# Module 00 Resources

### RES-01 Open Data Structures

- URL: https://opendatastructures.org/
- Use for: arrays, lists, hash tables, trees, heaps, and graphs.
- Local alternative: lessons in this module.
- Boundary: use as a data-structure reference, not as a replacement for the
  system-design tradeoff framing in the lessons.

### RES-02 CLRS Lecture Notes

- URL: https://ocw.mit.edu/courses/6-006-introduction-to-algorithms-spring-2020/pages/lecture-notes/
- Use for: asymptotic analysis, sorting, hashing, and graph algorithms.
- Local alternative: lessons in this module.

### RES-03 What Every Programmer Should Know About Memory

- URL: https://people.freebsd.org/~lstewart/articles/cpumemory.pdf
- Use for: locality and memory hierarchy limits on algorithmic claims.
- Local alternative: L02.

### RES-04 Computational Complexity

- URL: https://plato.stanford.edu/entries/computational-complexity/
- Use for: tractability, P, NP, and decision boundaries.
- Local alternative: L08.

### RES-05 Algorithms, 4th Edition site

- URL: https://algs4.cs.princeton.edu/home/
