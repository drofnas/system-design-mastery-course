# Week 44 Worksheet: Asynchronous-Workflow RFC and Defense

## RFC requirements

Use the course RFC template and include user outcome, workload, authority,
invariants, event/command contracts, delivery/ordering, outbox/CDC, consumers,
effects, workflow state/compensation, event time, lag/backpressure, poison,
replay/reconciliation, security/privacy, cost, telemetry, ownership, and
uncertainty.

Compare at least:

1. synchronous or single-database processing;
2. bounded database/broker queue;
3. retained log plus choreography or durable orchestration.

Use shared drivers. Define shadow publication, compatibility, bounded backfill,
dual-read comparison, cutover, rollback, decommission, and measurable reversal
conditions. Do not create two uncoordinated authorities.

## Defense record

Record reviewer roles, evidence commit, questions, answers, dissent, changed and
unchanged claims, follow-up owner/date, and a teach-back using a case in another
stack. Defend without AI assistance.

## Evaluation and remediation

Run structural gates before scoring. Preserve evaluation. If Revise or Repeat,
complete named lessons/exercises and create a dated revision or rerun that links
to—not overwrites—the original.

Module 11 creates no Gate 4 or capstone revision.
