## Executable evidence boundary

The Python 3.11 standard-library model emits deterministic schema-valid evidence
for sixteen strict same-input broken/repaired scenarios. Seven tests cover exact
inventory, deterministic reruns, hashes, one-control pair changes, named broken
failures, all repaired invariants, deduplication, snapshot recovery, joint
membership, and command-line output. Course validation independently reruns all
scenarios and rechecks the same contracts.

README, lessons, trials, and rubric consistently exclude production disk
durability, real-time availability, bounded networks, Byzantine tolerance,
security enforcement, performance proof, and regional survival. Distributed
transaction commit and messaging/workflow coordination remain out of scope.
