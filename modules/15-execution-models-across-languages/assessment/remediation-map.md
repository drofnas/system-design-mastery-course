# Module 15 Remediation Map

| Finding | Return to | New evidence, never replacement text |
|---|---|---|
| Work differs across runtimes | L06, EX-10 | New equivalence audit and rerun |
| Lifetime/retention model wrong | L01, EX-01–02 | Owner/release map and bounded trial |
| Scheduler/queue hidden | L02, EX-03–04 | Placement map and queue telemetry |
| Boundary trusts decoded bytes | L05, EX-14–15 | Negative validation fixture |
| Fan-out/deadline unsafe | L03, EX-06–08 | New isolated repair pair |
| Race or visibility unsupported | L04, EX-12–13 | Happens-before graph, tool run, oracle |
| Cleanup incomplete | L03, EX-08 | Cancellation/exception trial with zero deltas |
| Evidence chronology broken | L06, EX-17 | Repeat affected work with a new frozen baseline |
| Runtime decision unowned | L08, EX-18 | Separate ADR addendum and reviewed defense |

Revise creates a dated addendum. Repeat uses new seeds and preserves the failed
attempt. Evaluation never writes the learner's graded architecture.

## PESD 2.0 remediation

When a cross-cutting floor is missed, return to Lesson 8's PESD 2.0 extension
and the final exercise. Create a separate dated revision containing the missing
requirement/control/evidence mapping, owner, evidence boundary, failure check,
cost consequence, migration, and reversal trigger. Never edit the frozen
baseline or raw trial. A Pass creates no required remediation artifact.
