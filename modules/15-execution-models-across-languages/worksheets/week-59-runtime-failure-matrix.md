# Week 59 Runtime Failure Matrix

## Evidence rules

Preserve predictions and raw trials. Each F01–F09 pair uses the same seed,
logical input, and limits and changes exactly one control. Record scenario,
shared-input, config, and output hashes.

## Pair record

For each pair include target invariant; observed scheduler/memory/race/cancel/
resource/validation evidence; broken result; named repair; repaired result;
useful-work equivalence; causal explanation; competing explanation;
falsification; operations/security/cost/ownership effect; and evidence boundary.

## Readiness checks

All broken targets fail, all repaired I01–I10 pass, cleanup reaches zero after
grace, detector/static evidence is scoped, and no empirical metric is presented
as a universal language fact.
