# Northstar Pass Calibration Fixture

## Identity and frozen chronology

Manifest `manifests/pass.json` resolves A01–A11 and four A11 logs. A01 and all
F01–F08 predictions predate execution; sixteen A04 raw trials are immutable.
Each pair shares route/workload/profile/seed/input hash and changes one control.

## Routes, rendering, cache, and accessibility

The pinned Node/React/Chromium harness verifies all five routes. `/sky-events`
is static and varies on normalized region; `/events/:id` streams a public shell;
`/live` caches only its shell and obtains live data client-side; staff content is
server rendered with an island and `private, no-store`. Two-session probes never
place staff bytes in shared storage. Cache versions, validators, hits, misses,
purges, and bounded origin-failure behavior resolve. Axe results are paired with
keyboard order, focus visibility/restoration, semantic errors, zoom/reflow, and
explicit assistive-technology limitations.

## Browser work, performance, memory, dependencies, and traces

Task-to-paint traces decompose input delay, processing, and presentation delay.
Route budgets name population/percentile/conditions and keep lab and field data
separate. Repeated navigation identifies listeners, timers, nodes, heap/resource
deltas, and cleanup grace. The third-party policy has admission budgets,
isolation, fallback, privacy review, owner, and removal triggers. Sanitized trace
context links browser, edge, and origin without treating client input as authority.

## Failures and architecture leadership

F01–F08 broken targets fail and repaired trials restore I01–I10; raw evidence,
hashes, tool limits, and causal alternatives remain visible. The RFC decides per
route and covers no-change, boundary alternatives, operations, security,
accessibility, cost, ownership, migration, rollback, stops, and reversal.
Dissent narrows the edge seam. The defense, evaluation, and separate remediation
revision cite preserved evidence; one Chromium run is not generalized.
