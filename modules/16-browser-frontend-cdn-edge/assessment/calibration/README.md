# Module 16 Calibration

These Northstar-only fixtures calibrate evidence quality without exposing a
storefront capstone answer. Run Pass, Revise, and Repeat twice in isolated
deterministic evaluator sessions. Preserve each schema-valid raw JSON response,
its SHA-256, runtime/model settings, and unique isolation identity. Aggregate
with `scripts/check_calibration.py`; bands must agree and each R01–R10 score may
drift by at most one point.

The fixtures are deliberately concise assessment submissions, not exemplar
architectures. Their manifests enumerate artifacts so the evaluator can test
completeness without inventing evidence.
