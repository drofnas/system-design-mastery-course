# Module 17 Calibration

These Atlas-only fixtures calibrate evidence quality without exposing a commerce
capstone answer. Before readiness, evaluate Pass, Revise, and Repeat twice in
isolated, deterministic, read-only sessions. Preserve each schema-valid raw
response, SHA-256, runtime setting, and isolation identity. The deterministic
checker must confirm result bands and at most one point of per-criterion drift.

For calibration only, each fixture is the synthetic submission evidence record,
not a learner-written summary of missing underlying artifacts. Treat explicit
statements under its headings as authoritative evidence for the named synthetic
artifacts; do not infer facts that the fixture does not state. The manifest is
authoritative only for identity, artifact inventory, learning-log inventory,
baseline tag, and assistance disclosure. This calibration convention does not
weaken the assessment contract for real learner submissions.

Fixtures are assessment submissions, not exemplar architectures.
