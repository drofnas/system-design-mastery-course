# Module 17 Remediation Map

| Finding | Revisit | New evidence without overwriting |
|---|---|---|
| Shape, probability, or numerical error | Lesson 1; EX-01–EX-04 | Corrected derivation and hand reference |
| Token, attention, or generation defect | Lessons 2–3; EX-05–EX-07 | New conformance tests and internals addendum |
| Memory/capacity/cost gap | Lesson 4; EX-08–EX-09 | Reconciled sensitivity and capacity model |
| Measurement or causal gap | Lesson 5; EX-10 | New same-work repeated profile |
| Queue/admission/fairness failure | Lesson 6; EX-11–EX-13 | New bounded pair and recovery evidence |
| Cache privacy/version failure | Lesson 7; EX-14 | New two-tenant and invalidation pair |
| Precision quality failure | Lesson 7; EX-15 | New reference-corpus gate and rollback evidence |
| Provider containment failure | Lesson 7; EX-16 | New one-deadline compatible failover pair |
| Pair integrity failure | Lessons 5–7; EX-17 | New baseline and complete immutable pair set |
| Weak decision or teach-back | Lesson 8; EX-18 | Dated RFC revision and new recorded defense |

Repeat from a new baseline after any evidence-integrity or unresolved safety
failure. Otherwise preserve the original and submit a dated revision.
