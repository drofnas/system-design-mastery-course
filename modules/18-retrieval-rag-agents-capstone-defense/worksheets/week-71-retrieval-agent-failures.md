# Week 71 — Immutable paired failure evidence

Never overwrite raw trials or the Week 69 predictions.

## Trial manifest

For every F01–F08 broken/repaired pair record scenario path, trial path, hashes, seed, changed control, target invariant, start/end time, and operator.

## Equivalence proof

Show identical workload, seed, corpus hash, and evaluation-set hash plus exactly one control difference. Explain any nondeterminism or reject the pair.

## Failure matrix

For each pair: broken observation, causal mechanism, repaired observation, all invariant results, user/security/operating/cost consequence, residual risk, and monitoring signal.

## Controlled incident

Choose the highest-risk failure. Create a timeline, detection/control gaps, contributing causes, containment, repair, validation, owners, and deadlines using the incident template.

## Updated threat and cost evidence

Quantify attack surface, privilege, egress, audit, provider attempts, retrieval work, failure amplification, and operating burden.
