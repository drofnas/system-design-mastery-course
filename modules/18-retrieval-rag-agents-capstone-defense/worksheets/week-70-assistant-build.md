# Week 70 — Independent assistant build and evaluation

Use this for the independent commerce AI Shopping Assistant. CivicAid is instruction, not the answer.

## Scope and interfaces

Declare user outcome, non-goals, corpus boundaries, tool boundaries, and failure semantics.

## Retrieval implementation

Document lexical, exact vector, HNSW, hybrid, reranking, access filtering, index versioning, and deterministic configuration. Link automated checks and exact-search oracles.

## Evidence and answer policy

Define citation/version binding, freshness and revocation objectives, claim-support judgment, refusal behavior, and evidence limitations.

## Tool and workflow controls

List schemas, policy source, credentials, approvals, audit fields, history, checkpoints, replay, idempotency, cancellation, compensation, and step/time/cost budgets.

## Evaluation report

Report dataset/hash, measures, slices, confidence limits, regressions, release decision, and raw evidence paths. Separate contract proof from production relevance/model quality.

## Implementation review

Record reviewer challenges, accepted changes, rejected suggestions with reasons, and unresolved risks.
