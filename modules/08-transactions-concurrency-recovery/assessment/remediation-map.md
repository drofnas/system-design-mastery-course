# Module 8 Remediation Map

| Finding area | Return to | Produce separately |
|---|---|---|
| Invariant or boundary | Lesson 1, EX-01–EX-02 | dated authority/boundary addendum |
| History or isolation | Lesson 2, EX-03–EX-04 | new annotated schedule and graph |
| Locks/deadlock/retry | Lesson 3, EX-05–EX-06 | bounded retry and cleanup rerun |
| OCC/MVCC/write skew | Lesson 4, EX-07–EX-08 | visibility/validation sensitivity addendum |
| Constraints/workflow | Lesson 5, EX-09–EX-10 | crash and reconciliation addendum |
| WAL/durable ack | Lesson 6, EX-11–EX-12 | new crash-boundary trace |
| Restore/RTO/RPO | Lesson 7, EX-13–EX-14 | new isolated restore exercise |
| Evidence integrity | Lessons 2–7, EX-15 | fresh baseline and trials; never repair raw evidence |
| ADR/defense | Lesson 8, EX-16 | dated ADR/defense revision |

Missing or invalid original evidence may require Repeat. Remediation never
retroactively repairs an overwritten baseline or fabricated trial.

## PESD 2.0 remediation

When a cross-cutting floor is missed, return to Lesson 8's PESD 2.0 extension
and the final exercise. Create a separate dated revision containing the missing
requirement/control/evidence mapping, owner, evidence boundary, failure check,
cost consequence, migration, and reversal trigger. Never edit the frozen
baseline or raw trial. A Pass creates no required remediation artifact.
