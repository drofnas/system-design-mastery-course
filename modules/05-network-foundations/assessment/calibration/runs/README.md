# Raw Calibration Runs

These six files are the unedited final JSON responses from separate read-only evaluator contexts. Each context received one fixture, the assessment contract, rubric, remediation map, evaluator prompt, shared evaluation schema, and that fixture's manifest. Expected bands and other fixture results were withheld.

`discarded/` preserves two candidate second-run outputs rejected by the
deterministic arithmetic check. They are audit records, not accepted runs.
