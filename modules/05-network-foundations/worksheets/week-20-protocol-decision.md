# Week 20 Protocol Decision and Defense Worksheet

## Shared drivers

Define client population, operations, workload, network distributions, security
boundary, cost limit, ownership, and user thresholds before naming a protocol.

## Alternatives

Compare at least HTTP/1.1 pooling, HTTP/2, and HTTP/3 with fallback. Use the same
drivers and cite measured, modeled, and external evidence separately.

## Migration and operation

Specify compatibility, staged exposure, fallback, telemetry, capacity,
certificate/key ownership, incident response, rollback, decommissioning, and
reversal thresholds.

## Teach-back record

Explain ordering and stream isolation from first principles. Record questions,
disagreement, changed claims, unresolved uncertainty, follow-up owner, and a
separate revision path.
