# Home Lab Guide

This course is designed for one learner on one ordinary development machine. Labs exist to reinforce understanding; they are not optional project evidence or certification gates.

## Baseline

Most modules need:

- A text editor
- Git for cloning the repository
- Python 3.11 or newer
- A Unix-like shell, macOS Terminal, Linux shell, or Ubuntu on WSL2

Some deep labs may additionally use Docker, Node, Chromium, or language-specific toolchains. Module lab READMEs name their requirements.

## Pacing Labs

- Review path: skip labs unless you want a quick demonstration.
- Standard path: run the smallest reinforcement lab or reason through its output.
- Deep path: run broader matrices, compare implementations, or complete optional projects.

## Safety

Run labs locally on loopback or isolated processes. Do not use employer secrets, production data, private customer data, or cloud resources unless you know exactly what you are doing and can keep the work isolated.

## Troubleshooting

If a lab is too heavy for your machine, read the lab README, run the smallest scenario, and use the answer explanations to understand the mechanism. Heavy platform matrices are optional deep dives.
